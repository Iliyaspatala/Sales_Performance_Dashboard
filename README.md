# Sales Performance Dashboard

## Overview
Interactive Sales Performance Dashboard built using Power BI,
analyzing 51,292 records across regions, categories and years.

## Tools Used
- Power BI Desktop
- Microsoft Excel
- Dataset: Superstore Sales (Kaggle)

## Key Metrics
- Total Sales: $13M
- Total Profit: $1.47M
- Total Quantity: 178K

## Visuals
- KPI Cards - Sales, Profit, Quantity
- Line Chart - Year wise Sales Trend
- Bar Chart - Region wise Sales
- Donut Chart - Category wise Sales

## Key Insights
- Central region has highest sale
